# Ekspor UI PahaMIn dari Figma

Gambar di folder ini adalah acuan visual untuk implementasi UI PahaMIn. Nama berakhiran angka ditambahkan bila nama ekspor bertabrakan di Windows.

Sumber: `PahamIn (1).zip`, ekspor layar yang diberikan pengguna.

Jangan mengganti desain dari awal. Cocokkan layout, warna, tipografi, ikon, jarak, dan pola interaksi pada gambar sebelum menghubungkan data dan perilaku.

Screenshots bersifat referensi visual; implementasi harus menggunakan komponen web yang responsif, bukan menampilkan screenshot sebagai UI.
