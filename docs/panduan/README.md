# Indeks Panduan PahaMIn

Folder ini mengumpulkan panduan kerja tim, acuan desain, dan aturan coding PahaMIn. Gunakan daftar berikut untuk menemukan dokumen yang sesuai.

## Isi Folder

- [Panduan Persiapan Tim](Panduan_Persiapan_Tim_Proyek_PahaMIn.docx): pembagian tanggung jawab, tools, dan persiapan kerja anggota tim.
- [Panduan Prompt AI](Panduan_Prompt_AI.md): cara memilih prompt peran, menyusun brief, dan memeriksa hasil AI.
- [Acuan UI/UX Figma](UI_DESIGN_REFERENCE.md): aturan implementasi berdasarkan desain yang sudah dibuat.
- [Aturan Coding dan Arsitektur](.cursorrules): sumber lengkap aturan yang wajib diikuti saat mengubah kode.

## Referensi Proyek

- [SKPL / SRS](../SKPL.md): kebutuhan perangkat lunak, diagram use case, skenario, dan class diagram.
- [Konteks proyek terbaru](../CONTEKST_PROYEK3.md): status teknis, pembagian tim, keputusan, dan rencana sprint yang tercatat.
- [Product Requirements Document](../project-requirements.md): kebutuhan produk, scope, alur, dan keputusan terbuka.
- [Design brief](../design-brief.md): prinsip, token visual, layar, komponen, state, responsive behaviour, dan aksesibilitas.
- [Ekspor layar Figma](../design-reference/figma-exports/README.md): indeks referensi visual yang digunakan saat membangun UI.
- [Prompt peran AI](../prompts/): prompt untuk perencanaan, desain API, QA, review, perbaikan, dan dokumentasi.

## Urutan Membaca

1. Baca panduan persiapan tim untuk memahami PIC dan tools.
2. Baca konteks proyek dan PRD untuk memahami status serta scope kerja.
3. Sebelum mengubah kode, baca aturan coding dan arsitektur.
4. Untuk pekerjaan UI, baca acuan UI/UX dan design brief, lalu buka ekspor layar yang relevan.
5. Untuk menggunakan AI, baca panduan prompt dan prompt peran yang sesuai.

`AGENTS.md` dan `.cursorrules` di root repository menunjuk ke aturan coding lengkap di folder ini.
